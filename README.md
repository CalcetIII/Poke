# Arcade Club

Portal de juegos web estáticos, listos para jugar desde el navegador:

- `poke.html` — Pixel Survivors, supervivencia elemental.
- `snake.html` — Snake, compatible con teclado y controles táctiles.
- `pong.html` — Pong contra el ordenador, con controles táctiles.
- `tres-en-raya.html` — Tres en raya para dos jugadores.
- `neon-run.html` — plataformas de ritmo con cuatro niveles y controles táctiles.
- `turbo-arena.html` — fútbol de coches contra la CPU, con salto y turbo.

`index.html` es el catálogo y punto de entrada de GitHub Pages. El flujo de GitHub Actions publica automáticamente el sitio al actualizar la rama `main`.
